# 平台顺序：Windows 与 macOS 同期，Linux 与移动端随后；移动端零新增功能

范围是三桌面加移动端最低适配（三桌面 + 移动最低），但四者不可能同时推进。我们决定：
**Windows 与 macOS 同期做**，**Linux 与移动端随后**；移动端在第一阶段的状态是
**保底可编译可运行、零新增功能、不参与任何验收**。

## Consequences

- **本机没有 macOS 机器**，所以「同期」实际只能是「代码同期写、验证滞后」——
  Gate A-M 会长期是欠账，macOS 的 SR 后端、Metal 路径与那组带宽数字（190 GB/s、4K 单页 0.348 ms）
  都还没有实测。这不是靠决心能解决的问题，需要一台机器或一位测试者。
- 移动端**明确不做**：GPU texture 后端、超分、OCR 翻译、上色、视频。
  保留现有 Flutter Image + CoreML / ncnn 链路。
- 任何移动端专属工作**必须先写进 `docs/ROADMAP.md`** 才允许动手——否则它会持续消耗注意力却永远排不上优先级。
- 「个人自用」这个交付目标不会自动约束范围，这条顺序才是实际起作用的那道闸。
