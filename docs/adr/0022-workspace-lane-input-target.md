# ADR-0022：泳道输入即时归属与视觉定位分离

日期：2026-10-11。状态：已接受。

## 背景

泳道目前通过悬停驻留激活来决定操作上下文，并拦截非激活内容的第一次点击。输入因此需要等待驻留、下一帧及定位动画；拦截层也阻止内容接收第一次滚轮。用户要求操作直接、连续，同时保留泳道从屏幕边缘回拉到完整显示、Reader 独占和既有操作绑定系统。

访谈记录：[泳道输入与视觉聚焦访谈](../workspace-input-focus-interview.md)。本决策覆盖 ADR-0014 中“第一次点击只激活、不执行内容”的规则，以及以视觉激活状态作为唯一输入归属的假设；绑定解析继续遵循 ADR-0015。

## 决策

1. **输入目标、绑定上下文、视觉定位分别负责不同事情。** 默认鼠标所在的可用泳道立即成为键盘输入目标，无需等待悬停或滚动。目标选择只向现有绑定系统报告 reader / video / panel / editor / modal 等上下文，不另建绑定规则或动作执行器。指针离开泳道、进入空白时保留最近有效目标；显式键盘/导航切换可更新目标。
2. **第一下操作执行内容。** 点击命中的按钮、阅读区或视频控制立即执行，并确认泳道。滚轮直接进入命中内容已有的输入采集/Scrollable，继续使用 Flutter 信号仲裁保证绑定与原生滚动只消费一次。连续滚动期间锁定起始泳道，停止自动定位；若命中路径变化，不能把余下信号交给另一条泳道。轨和栏头原有入口保留。
3. **视觉定位保留停留触发。** 鼠标经过只更新输入目标，停留后才更新视觉激活并最小移动，使目标完整可见。目标宽于视口时尽量显示可用区域。Reader 窄缝仅在不损害目标完整可见时保留。Reader 独占偏好继续稳定阅读器宽度，不因目标切换重排/重解图片。
4. **直接手势优先。** 按下、长按、拖动或触控板序列暂停并停止定位动画，释放后重新根据最新状态定位。新请求合并为一次下一帧计算，以临界阻尼运动从当前位置承接当前速度，同一目标不重启动画；条带移动产生的合成悬停不连锁定位，实际鼠标移动可更新目标。点击不因位置变化而丢失；键盘不等待动画。
5. **编辑和弹层拥有交互。** EditableText（包括输入法组合）保留真实焦点，并报告 editor；不将其键盘冒泡转为阅读器或 global 动作。普通弹层/模态路由与轮盘期间不跟随鼠标或自动定位，reader 的直接入口及延迟长按也遵守保护。窗口失焦暂停快捷键。轮盘沿用唤出它的派发器及当时上下文，结束后恢复普通规则。
6. **边缘揭示沿用设置。** 保留揭示是否激活与离开恢复偏好。临时揭示只看一眼仍可恢复；内容上的明确点击/滚轮认领它，不再自动收回。揭示内容的输入即时可用。
7. **每泳道可调整行为。** 设置页使用单个“泳道交互”区，通过 Tab 切换泳道，共用键盘目标跟随鼠标、悬停后完整显示、定位等待时间表单，复用 workspace interaction 快照的持久化、备份与同步边界。旧配置缺省采用鼠标跟随，定位开关/等待时间继承原有 reader/panel 设置。泳道偏好不编辑操作绑定。

## 后果与验证

视觉 activeLane 与瞬态输入目标不再总相同；输入目标不触发配置写盘。内容缓存与 Reader 稳定宽度继续有效。旧版“首击吸收”验收由本 ADR 替代。

验证包含非激活泳道首次点击和滚轮、驻留前键盘上下文、编辑/弹层保护、手势和连续滚轮期间的定位抑制、每泳道设置的旧配置兼容与 JSON 往返、完整显示的几何约束。真机鼠标/触控板与输入法的手感仍需实际使用确认；时长是可调整参数，不以静态代码估算冒充性能测量。
