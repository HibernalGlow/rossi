# 封面「直接阅读」按钮 实机验收判据

给每本漫画的封面正中加一颗按钮：点它就**不进详情页、直接起读**（有进度就续读）。
动机是下载 / 本地 / 历史这些场合早就知道详情是什么，点封面进详情页只是多一步。

本文件只回答一件事 —— **怎么判定一条真的通了**。范围与取舍写在文末「明确不做」，
判据的作用与 [file-manager-acceptance.md](file-manager-acceptance.md) 相同：砍掉「看起来做了」的机会。

冻结信息：2026-09-21，对着**工作区**跑（这棵树同时有别的会话在未提交的改动里）。

**报告格式**：不通过时给 **条目号 + 控制台片段**，不要给描述。

## 0. 入库红线：这三件事不算完成

1. **`flutter analyze` 干净 ≠ 起读真的能到阅读器。** 本轮静态过、10 条组件测试与 22 条策略测试全绿，
   但它们证明不了「按下之后翻到了对的那一章」。
2. **按钮画出来了 ≠ 点它走的是本地那条路。** 远程书与已下载书外观完全一样，
   区别只能看**有没有网络请求**（条目 1.3 用飞行模式卡这一点）。
3. **「续读」跳回上次页码 ≠ 因为你的按钮。** 从详情页进阅读器也有同样效果，
   所以每条续读都要**先退到封面再点按钮**，不能连着上一次的结果判断。

## 1. R1 — 起读正确性（最高风险，先跑这组）

观察点：一本**从没读过**的书与一本**读到中途**的书各准备一份，逐条操作后读**章节号 + 左下角页号**。

| # | 场景 | 通过判据 |
|---|---|---|
| 1.1 | 远程插件漫画、没读过 | 点按钮 → 圆圈变进度圈（回源问一次章节列表）→ 进阅读器，落在**第一章** |
| 1.2 | 同一本、读到第 3 章第 12 页 | 点按钮 → 落在**第 3 章第 12 页**，与从详情页点「开始阅读」的结果逐字一致 |
| 1.3 | 这本书**已经下载过整本** | **开飞行模式**再点按钮 → 仍然进得去、不转圈或一闪而过、无「无法开始阅读」提示。走的是下载记录里的章节表，不该联网 |
| 1.4 | 本地文件（文件夹 / cbz / zip） | 点按钮直接进阅读器；**没有**「加载失败，请重试」，控制台没有 `plugin_not_found:local` |
| 1.5 | 远程书、断网 | 进度圈结束后弹「无法开始阅读，请稍后重试」，**停在原页面**，不推进一个空白阅读器 |
| 1.6 | 连点 | 快速连点同一颗 5 次 → 控制台只有**一次**起读，阅读器不叠两层 |

## 2. R2 — 一颗封面不能有两种歧义

| # | 通过判据 |
|---|---|
| 2.1 | 点封面**中间圆圈** → 起读；点**圆圈以外**（标题条、边角的空白）→ 仍然进详情页 |
| 2.2 | 点右上角**下载角标** → 只触发下载，不会顺带进阅读器或详情页 |
| 2.3 | 点左上角**汉化 / 喜欢画师角标** → 只显示提示，不误触起读 |
| 2.4 | **长按**卡片任意处（含圆圈上）→ 删除确认框 / 右键菜单照旧，不会因为按钮在场而失灵 |
| 2.5 | 进**多选模式** → 圆圈整颗消失（此时点封面是勾选，绝不该起读）；退出多选又回来 |
| 2.6 | 阅读器里按返回 → 回到**点按钮之前那一页**，不是详情页 |
| 2.7 | **封面取图失败**的那一格（断网或图源挂了 → 封面上是重载图标）：重载图标在**顶边居中**、播放圆圈在**正中**，两者不叠；点顶边那颗仍能重新拉封面，点圆圈仍起读 |

## 3. R3 — 开关要往返验

| # | 通过判据 |
|---|---|
| 3.1 | 「设置 → 书架 → 卡片角标 → 阅读按钮」存在，默认**开** |

## 4. R4 — 显示方式按平台分岔

| # | 通过判据 |
|---|---|
| 4.1 | **桌面**（Windows / macOS / Linux）：鼠标不在卡片上时圆圈**看不见**；移上去约 0.1 秒浮出并放大到实形；移出后收起 |
| 4.2 | 桌面隐藏态**点不到**：鼠标不悬停时点封面正中 → 进详情页（看不见却能点是坏界面） |
| 4.3 | **触屏**（Android / iOS）：圆圈**常驻**，不需要先碰一下才出现 |
| 4.4 | 密网格（小封面，一屏 5~6 列）下圆圈仍看得清、点得中；横滑卡（大封面）下不至于占掉半张封面 |

## 6. 明确不做

1. **不给「进度条 / 覆盖率」类装饰**：本轮只有「起读」这一个动作，不加「读到 40%」这类角标。
2. **不做长按菜单里的「直接阅读」项**：口径是先定「悬停浮出 + 触屏常显」，长按菜单那一份没排进来。
3. **不改详情页的「开始阅读」落点**：详情页那套（桌面并进操作行 / 触屏悬浮按钮）保持原样。
4. **不动下载中 / 未下载项的角标语义**：远程书**不会**因为点了按钮就先下载 —— 那是回源起读，
   要下载仍然点右上角那颗。
5. **不统一「本地直接进阅读器」的四处历史重复代码**：`openComicItem`、`ComicSimplifyEntry`
   两处、`ComicEntryWidget` 各自还有一份本地分支，本轮没有把它们并到一处（改动面太大，
   且这棵树同时在被别的会话编辑）。新的那份口径写在 `lib/util/comic/comic_quick_read.dart`。
6. **不做「续读优先」的可配置化**：本轮定死为「有历史就续读」，没有再加一个开关。
