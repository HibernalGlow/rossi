# 阅读洞察卡片的小尺寸内容适配

卡片外框继续由工作台跨度确定，内容不能反向改变槽位宽高。根据内容类型适配，
不把所有图表都切成固定像素的“上一屏 / 下一屏”。

- 连续阅读：空间足够时合并显示摘要与趋势；小卡片分为“摘要”和“趋势”，
  上下箭头、可点击展开的段名 / 进度合并在标题右侧，正文不再预留底部操作行。
  窄卡优先缩短段名，极窄时保留展开图标，不换行占用正文。切换复用 `RetainedPanelSwitcher` 的弹簧，
  增加可选纵向轴，默认横向行为不变。调整宽度、折叠再展开保留当前段。
- 阅读热力：始终保留完整七个星期。按宽度将每格汇总为 1、2 或 6 小时，
  以汇总格的最大值归一颜色，明确标注每格时长；汇总不丢样本，也不改变原历史聚合。
  每格时长和展开入口移至标题栏；高度连七行与文字都放不下时，正文显示高峰摘要，
  标题保留展开入口，不缩小字号硬塞矩阵。
- 完整视图：复用 `CommonPopupBox` / `PopupPanel` 托盘弹层。热力详情保留
  原逐小时矩阵、星期 / 小时选择器与精确记录数。弹层可以滚动，但上述卡片正文不嵌套滚动。

两张卡片通过 `CollapsibleCard.scrollContent = false` 消费实际有界高度。
`CardHeaderActions` 将正文持有的切段与选择状态绑定到外壳标题，帧尾更新避免布局反向改父，
正文移除或卡片销毁会释放绑定。其他卡片仍使用原默认行为。原历史窗口、查询、统计语义和布局持久化继续复用。
Breeze 没有对应工作台统计卡片；mImageViewer 的原生性能统计不能替代阅读记录洞察，
本次仅是既有洞察上的 Flutter 展示扩展。

回归验证窄卡、大字号、不同高度、切段中外框不变、调整宽度保留段、
全七行展示、各时间粒度总和一致、统一弹层展开与返回。
