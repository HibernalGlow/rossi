# 藏书空间与共用面板的 M3 Expressive 展示

2026-10-13。

首页收藏/历史/下载沿用 FolderShelfBloc；书签面板、历史面板与文件管理器沿用
LibraryEntry 与现有数据服务。这次变化位于展示层，不增加路由、视图枚举或数据库实体。

## 组合与面积

「展墙」内可分别开关主视觉、内容分区、不对称，关闭主视觉仍可用不对称与分区。
偏好按首页用途、书签、历史、文件管理器分别保存。文件管理器首次保留既有六档样式，
通过「展墙」开启新的排列；树形和分栏继续使用核心的原有快照和样式。

展示设置收进原有顶栏的「展墙设置」按钮，以弹出菜单调整，不单独占用正文行。
同一颗键长按 = 直接在展墙与普通视图之间翻转，只改「展墙」这一项，尺寸、分区、空隙小组件
等偏好原样保留；快开关与面板「应用」走同一条落盘路径，所以换设备照样同步。
面积选项为原图比例、跟随排序、内容数量、占用体积、最近使用、阅读状态、综合；没有数据的选项
会标为不可选。面积只改变视觉权重，不重新排序。大卡最多约占条目数的 28%，每行最多
一张，宽度只在 1–2 个槽位间变化，不使用密集回填。分区在原排序的连续段间加标题，
所以按标题排序时同类分区可以多次出现，避免暗中改变排序结果。

## 设置面板的分组

「展墙自定义」原先是一条纵向长卷，尺寸、布局、空隙、封面向导、权重全平铺在
一起。现在改成**一条连续滚动流**：尺寸 / 布局 / 组件 / 封面 / 权重依次向下衔接，
段落之间只用一条细分隔线隔开，用户可以一路滚过全部分组，不必先点页签再看内容。

底部导航条是这条流的**目录与位置指示**：滚到哪一段它自己亮哪一段（scroll-spy），
点它则滚到对应段首。面板高度整张固定，导航条的落点不随内容或分段变化；分段标题
不再承担「切页」职责，所以也不会在换页时上下漂。组件段内的预览网格随主滚动流
一起滚，不另起内层滚动条。

面板不再保留「恢复默认 / 取消 / 应用」那一行按钮：主出口「应用」做成导航条右侧
的悬浮图标，取消与恢复默认收进标题栏右侧的两颗小图标。省下的高度留给滚动内容，
底部动作条消失后导航条就是整张卡片唯一的一排落点。

尺寸类滑块不再五根并排的进度条：宽面板里排成两列度量卡（卡片宽度 / 高度、
间距 / 图片尺寸、大小对比），窄屏自动退回单列；封面向导与信号权重各自成页，
前者只在宿主支持原位详情时出现，后者只在这面墙有权重信号时出现。

## 空隙与组件

不规则轮廓留下的空白由「随机图形」与「小组件」两种填充物处理：图形是纯装饰，
小组件把这一墙的汇总面说一遍（新增 / 阅读节律 / 未读存量 / 里程碑等）。两者共用
一次总口径（不填充 / 随机图形 / 小组件 / 组件 + 图形），单项开关缺键即开。

设置收进展墙自定义面板的「组件」页签：同一屏里调整总口径、随机图形总开关、
每一款组件与每一款图形；顶部给出「当前效果」预览，网格里每一项都用**真实
builder / painter** 在真实槽位尺寸下渲染，不做缩略图替代。全部开启 / 全部关闭
只作用于当前页签，恢复默认只还原与空隙有关的四项，尺寸、排序与权重原样保留。

随机图形有八款轮廓家族（有机团 / 星芒 / 四叶草 / 宝石 / 拱门 / 花形 / 圆环 / 波纹），
种子仍决定具体几何与配色；单项开关全关时退回有机团，保证「被填的空隙」不会变回
空白块。新增六款小组件：收官进度、阅读热力、星期节律、收藏跨度、待读存量、下一
里程碑；数据面只读 `LibraryEntry`，不查库、不接 Bloc。偏好仍随 `gapFill` /
`gapShapes` / `gapWidgets` 一起落盘与参与同步，内容串按 id 排序。

原图比例按已有图片解码结果决定宽位和卡片高度，不改变原排序。尺寸回报批量应用，
滚动或详情展开期间延后重排；空闲更新用可见封面锚点保持浏览上下文。极端长图以完整
画面缩入有界容器。页面列表使用同一个展墙设置，保留页序、搜索、当前页与阅读跟随。

## 原位详情

书本点击在当前行下方直接加载并展开真实详情内容，原封面改变选中形状。当前行前方的卡片保持位置。
切换到下方书本时通过封面锚点补偿旧详情收起造成的位移；关闭恢复展开前的滚动位置。
已展开的详情保留在滚动缓存之外，避免离开视口后丢失章节状态。

原位区域使用原 ComicInfo 的 Bloc、章节、收藏、下载和阅读消费者，采用独立的内容布局：
工具按钮、Tag 与简介、保留原图的横向预览轨道、分批展开的章节区。不会重复书名封面，
没有第二层「完整详情」开关，不嵌入旧页的 Scaffold 或独立纵向滚动视图。
本地来源通过现有 LocalPageSource 与缩略图服务读取真实页数、预览与路径，收起后关闭会话。
六档列表/网格和书签/历史时间线也支持当前行展开。上下文菜单的显式「打开」仍沿用原动作。

文件管理器单击、双击和多选仍由既有核心决定。独立的信息入口展开预览，目录默认显示
层级列表，可切换内部缩略图；箭头展开子目录，名称打开文件或进入目录。搜索快照未包含
目标时给出进入入口，不把缺失节点伪装成持续加载。

文件图片、归档封面与文件夹合成图使用 contain。多图合成复用 thumb_loader 的候选
选择与排序，把完整图片等比置入各自区域，周围使用取自原图的暗色背景；缓存策略升级
为 fitted4-v2，避免继续命中已经裁切的旧图。

## 真实统计

目录数量与体积使用 UI 专用的异步文件枚举，默认当前层，可选递归。数量包含目录条目，
字节仅累计普通文件，不跟随链接，并遵循隐藏文件设置。两条并发扫描、128 项缓存、
2 分钟有效期；换目录或请求取消后旧结果不能回写，当前目录刷新/变更会失效缓存。
无权限区域标为「至少」，预览中的 childNames 数量不能充当目录总数。

后台统计仅用于展示面积与摘要，不接管 Rust 的排序、导航、缩略图或文件操作；滚动中的
画布不因统计完成重新分配槽位，改变展示设置后再计算。

## 封面层级

横向书列与书架共用 ComicCoverSurface，沿用角标策略、画师/Tag/语言判定与阅读/下载动作。
画师为次要色调与心形；普通 Tag 为中性色与 #；语言状态使用主/第三色调及文字标记。
元信息自然换行，长名称受可用宽度约束；窄封面给下载操作留独立空间。

下载按钮统一色调容器与 48dp 命中区，状态图标与进度环可同时显示，排队时防止连点。
阅读按钮固定在封面正中央，闲置时半透明，保留触屏常显、桌面悬停、键盘焦点和预热反馈；可见圆形与
48dp 命中区分开。底部三行标题使用渐进遮罩确保可读，关注画师不再使用错误色或粗边框。
所有新色调随主题明暗变化，原位揭示与按钮效果尊重系统减少动画设置。

展墙的普通卡片与主视觉同样使用中心阅读悬浮键，信息键悬浮在封面右下方；
不再增加操作底栏。窄卡标题叠在封面上，已有标题的首页封面不重复绘制。

## 验证与预览

共享布局测试覆盖顺序、面积上限、组合开关、中段滚动、切换锚点、六档原位展开、
220–1100dp 宽度与 48dp 操作入口。文件预览测试分别验证箭头与名称动作；统计测试
验证递归、隐藏文件、链接、不完整结果及取消。既有文件管理器和角标策略测试继续使用。
