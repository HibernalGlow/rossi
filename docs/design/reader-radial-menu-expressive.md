# 阅读轮盘的 Material 3 Expressive 展示设计

日期：2026-10-13

## 已确认的交互

操作按钮采用 Apple Watch 应用视图式的紧凑蜂窝排列，从中心向外填满。
中心也放操作按钮，取消旧同心环的中心空洞与空槽占位。提示和当前完整标签
移至下方的小提示胶囊。去掉整块圆盘底，只保留各按钮的主题色表面、聚焦
高亮及阅读浮层的遮罩。阅读时只显示已配置条目，编辑器额外显示可添加条目的空槽。

图标与短标签共同表达操作。首页/上一页、末页/下一页、放大/缩小使用不同
图标；动作链和跳转轮盘带附加标记。图标按绑定动作自动匹配，编辑器可以覆盖
或恢复自动。覆盖使用字符串 `iconId`，随配置保存与导入导出，不改变动作。
阅读时自动图标通过现有核心解析器按当前 reader/video 上下文确定。

鼠标附近局部放大，外围有限平移；停下后弹簧落位，不累积漂移。聚焦位置保持
稳定，视口边缘连续阻尼，周围按钮按剩余空间缩小以避免遮挡。按钮展示与命中
使用同一份几何。按下时暂停正在移动的几何，拖动仍可改变目标，松手执行一次。
键盘选择也会将目标放大，辅助导航继续使用原组件的可访问列表。

## 实现边界

继续复用 `flutter_ray_menu` 的条目、逻辑槽位、指针路由、去重、键盘导航和
确认流程。只增加可替换展示/命中接口，未另写操作绑定解析器。
条目 id、层号与槽位编号仍用于配置和编辑；蜂窝位置不再表示旧扇区的方向。
已配置动作链、轮盘跳转和旧直连动作回退保持可用。

中心现在是按钮。取消通过空白处、再次右键、Escape 或原取消手势进行。
样式保留圆角按钮与圆形按钮；尺寸与旋转设置作用于蜂窝排列。旧文档的
innerRadius/sweepAngle 原样保留，新界面不再提供中心空洞和扇区扫角控件。

开关浮层与图标选择弹层复用 `CommonPopupOverlayMotion` / `CommonPopupRoute`；
悬停、平移、选中态和按压复用 `SpringLensValue` / `LensMetrics`。空间弹簧
保留速度与过冲，透明度使用 effects 档。减少动画和墨水屏直接落位。

密集配置保留所有条目；概览中外围标签会缩小，鼠标或键盘聚焦后放大。
触摸可以选择当前可见按钮，辅助导航提供原有列表；未声称密集概览里的
每一个小按钮都具有 48dp 触摸尺寸。

## 验证

几何测试覆盖 1/2/8/24/64 槽位、三层、放大字号、有限平移、完整视口、
聚焦目标尺寸和命中、空槽与禁用项，以及中心填满。Widget 测试覆盖悬停惯性、
静止落位、按下冻结、拖动执行、键盘、减少动画、图标覆盖与恢复自动。
阅读浮层回归覆盖点击、拖动松手、子轮盘、绑定确认、关闭中重开、入场中关闭。
Rust 测试验证 iconId 往返与旧配置兼容。预览使用实际 Flutter 组件与中文字体。
