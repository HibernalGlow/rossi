# 收藏 tag 验收清单

功能：把「喜欢画师」那套搬到 tag 上 —— 收藏一批 tag，命中就在卡片与详情页高亮；
每条收藏可以带**别名**，用来适配各个图源对同一个 tag 的不同写法。

- 判据（已跑，纯 Dart）：`test/favorite_tag_matcher_test.dart`（10 项）、
  `test/favorite_tag_parse_test.dart`（7 项）、
  `test/network/sync/settings_sync_block_test.dart` 里新增的收藏 tag 往返一项。
  这些**只证明逻辑与设置读写**，不证明下面的实机观感。
- 以下每条都要在真机/真窗口里看，勾完请把**条目号 + 控制台输出**回给我。

## 1. 入口与管理页

1. 设置 → 内容 → 「收藏 tag 管理」这一行存在，未添加时副标题是「暂未添加 tag」。
2. 进入管理页，「收藏 tag 高亮」开关**默认开**。
3. 输入框敲 `school_lolita | 学校萝莉 | School Lolita` 回车 → 出现一条收藏，
   本名 `school_lolita`，下面两颗别名 chip。
4. 再敲一遍同样的内容 → 提示「已经收藏过这个 tag」，列表**不出现第二条**。
5. 点条目上的 ＋ → 对话框里加一个别名 → 别名 chip 出现；点别名上的 × → 被移除。
6. 别名填一个与本名只是大小写/下划线不同的写法（如 `School_Lolita`）→
   提示「这个别名已经存在了」，不产生冗余别名。
7. 「批量导入/编辑」弹窗预填当前全表（`本名 | 别名` 语法），改完确认是**整表替换**。
8. 「导入文件 (TXT/JSON)」：`a\nb | c` 这种纯文本、`["a","b | c"]` 与
   `[{"name":"a","aliases":["b"]}]` 三种都能读进来，并且是**合并**不是覆盖。
9. 「清空全部」二次确认后列表空掉。

## 2. 高亮落点（四处，全对齐画师）

10. 详情页 tag 胶囊：命中收藏 tag 的那颗变琥珀色 + 前面有 `# `；
    命中喜欢画师的那颗前面是 `♥ `。两个都命中时按画师那颗的符号走。
11. 长按任意胶囊 → 菜单里除了「设为喜欢画师」「复制」，新增**独立**的
    「收藏此 tag」；点一下即收藏，再长按变成「取消收藏此 tag」。
12. 搜索/发现列表的封面卡：命中的那本有琥珀色封面边框 + 左上角 `#tag名` 角标。
13. 书架与历史里的行：命中行琥珀描边，封面左上角同样的 `#tag名` 角标。
14. 详情页头部来源 pill 右边出现 `#tag名` 徽标。
15. 只登记**别名**（例如某站写的 `学校萝莉`），从那个站进来的本子也亮 —— 这就是别名存在的意义。

## 3. 匹配口径

16. 大小写、全角/半角、`_` 与空格、包裹括号的差异**不需要**登记别名就会命中
    （登记 `School_Lolita` 后，`school lolita` / `ｓｃｈｏｏｌ　ｌｏｌｉｔａ` 也命中）。
17. 插件给的 `artist:xxx` 这类带命名空间前缀的 tag，收藏 `xxx` 即可命中。
18. **不**做子串兜底：收藏 `lolita`，某本只有 `school_lolita` ⇒ 不亮。
    （画师那条有 `contains` 兜底，tag 上会大面积误报，刻意不搬。）
19. 标题括号里的写法（`[Chinese]`、`[Complete]`）能命中，但只在插件没给对应标签时兜底；
    插件标签里已经有同一个词时以标签为准。

## 4. 开关与降噪

20. 关掉「收藏 tag 高亮」→ 上面四处**全部**不亮。
21. 关掉设置 → 书架 → 卡片角标 → 「收藏 tag 角标」→ 封面卡与书架行不再画角标/边框，
    但详情页的胶囊仍然变色（那颗不归卡片角标管）。
22. 收藏 tag 与喜欢画师互不影响：只命中其中一个时也照常显示，两个都命中时角标纵向排开不互相盖。
23. 超长 tag 名不溢出：角标里一行省略，管理页行内省略号，胶囊一行省略。

## 5. 云同步

24. A 机收藏（含别名）→ 同步 → B 机下载后同一份 tag 集生效；
    同一轮里 B 机的**画师名单**不变（画师仍是本机私有，刻意不同步）。
25. B 机自己新加的 tag 与 A 机那一份合并时以更新的那台为准（块级 LWW，与别的设置同口径）。

## 明确不做

- 别名自动映射：项目里没有 tag 翻译表（gtags 之类），跨站点的不同写法只能由用户登记。
- 子串/模糊兜底（理由见第 18 条）。
- 按站点分组的别名表、把别名同时用于屏蔽词或搜索建议。
- 高亮的动画与自定义配色（沿用画师那套琥珀色）。
