## 0. 入库红线

## 1. 摊开 / 收起

| # | 判据 | 通过标准 |
|---|---|---|
| T1 | 把承载文件管理器的泳道拖宽过阈值 | 导航那一组变成**五颗独立图标钮**（后退 / 前进 / 上一级 / 主页 / 刷新），不再是那颗四角带箭头的掌 |
| T2 | 阈值落在哪 | 约 550px 卡片宽度：拖过去那一下整行**不出现横向滚动**（摊开了却要滚 = 不通过，说明阈值定低了） |
| T3 | 拖窄回去 | 五颗收回成一颗掌；掌与旁边的图标钮**同高**，整行只有一个高度带 |
| T4 | 掌的落点 | 四个方向分别点得到各自的动作，中心圆只出刷新；点「左」不会顺带刷新 |
| T5 | 主页键三种入口（两种形态各验一次） | 单击回主页（没设过时＝把当前目录设为主页）；长按弹菜单；**宽形态下右键也弹同一份菜单** |
| T6 | 设置里关掉「启用主页键」 | 两种形态下主页那颗都整个消失，其余四颗/四向不受影响 |

## 2. MD3 观感

| # | 判据 | 通过标准 |
|---|---|---|
| M1 | 整行图标钮尺寸 | 全部 40 见方、图标 20，没有哪一颗明显比邻居小一圈 |
| M2 | 组间 | 导航｜主工具｜更多 之间各一条竖分隔线；组内间距 4，看着是「一簇」而不是「贴死」 |
| M3 | 选中态 | 展开搜索、打开文件树、开穿透模式、站在主页上 —— 这四颗亮起来是**淡色胶囊底 + 深色图标**，不是主色实心、也不是图标染成主色 |
| M4 | 悬停/按压 | 每颗（含视图/排序/更多三颗菜单键）都有状态层（水波纹或高亮圈），掌形除外 |
| M5 | 禁用态 | 请求在飞时整行图标统一变淡一档，不是有的灰有的亮 |
| M6 | 计数文本 | 「N 项」是次要文字色（`onSurfaceVariant`），不是正文白 |
| M7 | 浅色主题 | M3/M6 在浅色下同样分得清（选中态与正文的对比不塌） |

| # | 判据 | 通过标准 |

| G1 | 面包屑行尾那颗「路径操作」 | **仍是紧凑档**（它坐在文本行里，本轮刻意没跟着放大）；点开能收起/展开目录列、编辑路径 |
