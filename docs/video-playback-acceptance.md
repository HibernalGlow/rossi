# 视频播放验收清单

配套 `docs/video-playback-spec.md`（并集与排除项）与 ADR-0016（为什么用 media_kit / libmpv）。
本文只写**在真机上怎么判定这条功能对不对**，逐条给预期与判据。

静态层面已经过了，不必重复验：`dart analyze lib/` 干净、`flutter test test/video/` **61 条全过 0 skip**、
`cargo test -p rossi_local_core` 360 条、`flutter build macos --debug` 出包成功且包内含 `Mpv.framework`。

**mpv 那一层也不用真机验了**：`test/video/mpv_property_probe_test.dart` 五条探针已经把「出厂那份
mpv 认得我写的每个名字」「属性写下去回得来（倍率/音量/静音/单条循环/A–B/滤镜/字幕样式/纯音频/
音画漂移/暂停态定位）」「视频侧真的解出画面：元数据、逐帧 40 ms、截图落盘」「坏文件落到 failed」
「裸 Player 显式 `vid=auto` 后能出画面」「`sub-add` 的字幕能进轨列表也选得中」「音轨列得进、`aid` 选得中、
「只听声音」开→关画面回得来」跑成了断言。
跑它们不需要开 App：

```bash
flutter test test/video/mpv_property_probe_test.dart   # 名字表那条要先有 macOS 产物
```

所以下面每一条都是**只有跑起来才知道**的东西：画面、声音设备、手感、观感、生命周期。

```bash

```

**样本一条命令生成**（本机装了 ffmpeg 即可；ffmpeg 只是生成工具，产物是普通 mp4/mkv/zip）：

```bash

```

07_archive/mixed.zip          归档内含视频 → A7 E4

（原先的写法是「自己找个图片文件夹丢个 mp4 进去」—— 那样凑不齐上面这几类，而每一类都恰好对应一种只在真机才暴露的缺陷。）

- `001.jpg / 002.mp4 / 003.jpg`（视频夹在图片中间）
- 一个 `.mp4` + 同目录 `同名.zh-CN.srt`（外挂字幕）
- 一个带章节的 `.mkv`（多音轨更好）
- 一个整本都是视频的文件夹（验收「全视频也能有封面」）

## 1. 页与生命周期（最容易出问题的一类）

| # | 场景 | 预期 |
|---|---|---|
| A1 | 从静图页翻到视频页 | 视频页出现海报/首帧并开始播放；静图那页的解码不受影响 |
| A2 | 视频页 → 再翻一页（离开） | **上一段视频立刻不出声**（不许有残留音轨）。这是 ADR-0016 里点名的新约束 |
| A3 | 退出阅读 / 关闭这本书的 lane | 音频停、无残留进程；再进来能重新播 |
| A4 | 双页模式，一个槽位里两页都是视频 | 只有当前那页出声；另一页是静止画面不是第二条音频 |
| A5 | 视频页在**未激活**的泳道里点一下 | 这一次点击只把 lane 切过来（neoview 的「首击归工作台」），**不会**顺手暂停视频 |
| A6 | 整本都是视频的章节 | 书架/列表的封面是海报帧，**不是**白图或坏图。（坏图与「从来不出来」两个根因都已修：封面缓存不写 mp4 字节；海报那条路现在显式开 `vid=auto`，其机制由探针 ⑤ 守着 —— 这次再不出来就该看 `getTemporaryDirectory()` 与 `sub-add` 之外的东西了） |
| A7 | 归档里 >512 MB 的视频条目 | 给可懂的失败提示（`page_bytes` 有 512 MiB 上限），不是无限转圈 |

## 2. 控制条与手感（neoview 那一屏）

| # | 场景 | 预期 |
|---|---|---|
| B1 | 播放中不动鼠标 | 3 s 后控制条收起；暂停时常显 |
| B2 | 鼠标回到画面上 / 打开任一弹层 | 控制条出来；**弹层开着时不收起** |
| B3 | 点图钉 | 控制条常显；**换书、重启 App 后仍然是钉住的**（持久化） |
| B4 | 点画面中间 / 左 1/4 / 右 1/4 | 播放暂停 / −10 s / +10 s |
| B5 | 拖进度条 | 位置跟手；两端不越界；拖动时上方出现 160×90 的**该时刻**预览帧 + 时间气泡。**悬停（不按下）只出预览、不改播放位置**，鼠标划过整条轴也一样；落点是点击/拖动那一刻的事 |
| B6 | 预览帧验证 | 划到视频后段，预览显示的必须是后段的画面 —— 不是当前播放那一帧（这条以前是错的）。**播放中也一样**：预览自带解码器，不借主播放器；帧没到位时显示「定位中」而不是一张时间对不上的图 |
| B7 | 倍速弹层 | 滑杆按 0.25 步长吸附；预设 0.5/1/1.5/2；`1x ⇄` 回到上一个用过的倍速 |
| B8 | 音量弹层 | 拖到 0 自动显示为静音；恢复音量解除静音（这两个状态在上游是合成一条的） |
| B9 | 循环按钮 | 三态轮换：接下一页 → 本页重复 → 关闭；「接下一页」播完真的翻页，「本页重复」不翻页 |
| B10 | 快进档 | 打开后翻页输入（方向键 / 点击区）变成 ±10 s，不再是翻页 |
| B11 | 滤镜三值 + 重置 | 0–200% 实时生效（mpv 侧的 ÷2 换算已由探针断言过，所以这条不合格 = UI 层或顺序问题，不用怀疑属性名） |
| B12b | 暂停态标记 A 点 | 立刻能看到「A 已标」的中间态（按钮亮起）。这条以前在暂停时不刷新，已修 |
| B12 | A–B 打点 | 第一次标点 A，第二次标点 B 并立刻循环该区间；第三次在 A 之前则清空；进度条上区间有底色。**这里的单位坑已经踩过一次**（写成毫秒 ⇒ 循环段永远撞不到，且 mpv 不报错），属性值本身已由探针钉死，本条只验「区间真的循环 + 底色画在对的位置」 |
| B13 | 截图 | 文件落在 `~/Library/…/Documents(应用目录)/video_screenshots/`，**不写进漫画库目录**；命名 `screenshot_年-月-日_时-分-秒.png` |
| B14 | 信息表 | 时长/尺寸/DAR/帧率/码率/编码/音画漂移有值；探测不到的字段显示 `—` 而不是整行消失 |
| B15 | 画中画 | 小窗可关、能继续播；关掉后主画面回来 |
| B16 | 进度条底下（**波形条**） | 有音轨的视频：进度条后面垫一层响度柱，前后段的粗细看得出差；无音轨（或容器不认识）：**整条不画**，不出现空槽、不报错。**数据那条路（Dart→FRB→Rust→归一化→缓存）已经自动化了**，这里只剩「看起来像不像波形」 |
| B17 | 波形条与预览帧共存 | 有波形时拖动仍然出 160×90 的悬停预览帧；两者不互相遮挡到看不清 |
| B19 | 音轨弹层（多音轨的 .mkv） | 列表里只有真轨，**不出现 `auto` / `no` 两条伪轨**；选中态跟随，切完声音真的变了 |
| B20 | 「只听声音」开→关往返 | 关掉之后**画面必须回来**。这条以前是单向可验的（`video=no` 生效、写回 `yes` 不选轨），实测会留在永久黑屏，已改成走 `vid=auto`；探针 ⑦ 现在双向都钉 |
| B18 | 把 App 语言切到英文 | 控制条 tooltip、字幕/滤镜/音轨弹层、信息表、设置区「视频播放」全部变英文（约 60 条键）；不该看到中英混排 |

## 3. 字幕（两家合起来的那套）

| # | 场景 | 预期 |
|---|---|---|
| C1 | 同名 `movie.zh-CN.srt` 与 `movie.mp4` 同目录 | 自动挂上并选中；弹层里能看见它 |
| C2 | 归档里的 `movie.srt` | 也能挂上（先物化再 `sub-add`），路径不该报错 |
| C3 | 字幕弹层样式 | 字号 0.5–3 em、5 个颜色、底色 0–100%、底部 0–30%、「大号黄色」预设、「重置」都立即生效 |
| C4 | 弹层里在「外挂轨」与「容器内轨」之间切换 | 选中态互斥（不能两处同时显已选）。**列表里不该出现 `auto` / `no` 两条**（media_kit 造的伪轨，已滤掉）；侧挂那条显示的是文件名而不是轨号 |
| C5 | 关闭字幕 | 真的没有字幕；再选一条能回来 |
| C5b | 带章节的 `.mkv`：进度条上方与章节键 | 章节刻度线画在**真正的时间点**上（本轮把 `chapter-list.time` 从取整秒改成毫秒精度，之前每章起点会往前挪最多 0.9 s）；下一章/上一章跳过去后当前章节刻度跟着变。**没有章节的文件**：两条动作就是不适用，不该跳出一个「已跳到第 0 章」的假反馈。**章节的解析与跳转已经自动化了**（真实 mkv 探针：1.5 s 的起点、跳过去再跳回来），这里只剩刻度线**画得对不对位置** |
| C6 | 延迟键（字幕延迟 ±0.25 s） | 生效方向正确、能累计；**换一本书之后从 0 重新算**（曾经挂在模块全局上跟着下一本走） |

## 4. 键位与设置（这一轮新加的）

| # | 场景 | 预期 |
|---|---|---|
| D1 | 在视频页按 → / ← | ±10 s（**不是**翻页）；离开视频页后同一个键恢复成「向右翻页」 |
| D2 | 在视频页按 C / X / Z | 加速 / 减速 / 1x⇄上次；在静图页按它们**不该被吞掉**（没活动视频时按键照常冒泡） |
| D3 | MediaNext / MediaPrev（带媒体键的键盘） | ±10 s |
| D4 | 设置页「视频播放」区 | 自动播放 / 硬解 / 去隔行 / 图钉 / 自动隐藏 / 倍速上限 / 默认音量 / 自定义后缀 都能改，**重启后保持** |
| D5 | 自定义后缀填 `png` | 报「png 已经是图片后缀」并拒绝保存；填 `myvid` 后 `.myvid` 文件成为可播的一页（含封面与列表缩略图） |
| D6 | 「动图当视频播」开关 | 关掉时 GIF 页与改造前完全一致；打开后 GIF 走视频控制器（有暂停/逐帧），带 `[#dyna]` 的页无条件接管 |
| D7 | 默认音量改 40% 后重开一本书 | 起播就是 40%，且控制条上的读数也是 40% |
| D8 | 关闭「硬件解码」 | 播放仍继续（CPU 解码），不该花屏；开着时活动监视器里应有 VideoToolbox 相关负载。**这条现在是关键项**：media_kit 附着时会把 `hwdec` 写回 `auto`（㉑ 已修），所以要看**关掉的档**是否真的不走硬解 |

## 5. 与静态图链路的互不干扰（判据回归）

| # | 场景 | 预期 |
|---|---|---|
| E1 | 一本**纯图片**的书 | 翻页帧时间与改造前一致（判据 C：p95 ≤ 16.7 ms）。视频页不参与该采样 |
| E2 | 连读三本（其中一本含视频） | 判据 D：RSS 增幅 ≤ 5%，纹理/handle 计数不单调上升 —— 重点看进出视频页若干次之后 |
| E3 | 超分管线 | 视频页不该被送去超分（它不是位图页），静图页超分不受影响 |
| E4 | 归档直读 | RAR/ZIP 里含视频条目时，页数 = 图片页 + 视频页，且**不是** 0 页（页序改动的主要动机） |

## 6. 失败时我最需要的东西

任一条不符，请给我：控制台那一段（`task dev` 的输出，尤其 `mpv`/`media_kit`/`MissingPlugin` 字样）、
以及该条的编号。**别只描述现象** —— mpv 属性名和面板行为是一一对应的，有编号我能直接定位到方法。

已知最可能出问题的三处，按怀疑度排：B5/B6 预览帧（第一次悬停要等预览解码器把文件打开，
几百毫秒内是「定位中」；坏源会一直走占位 —— 这两条都不该影响播放）、
E2 资源回收（`VideoController` 与 mpv 实例的释放时机，现在多了预览那一台）、
D1（context 优先级依赖工作台上报活跃集合）。
原先并列第一梯队的「属性名/单位写错」这一类已经由探针收走了，出问题请优先往**生命周期与竞态**上想。

| E5 | 反复进出视频页 10 次（翻页、切泳道都算） | 每次都**第一下就出画面**。同进程里已经起过别的 mpv 实例时，第一次 load 偶尔什么都不上报（探针实测 5 次撞 2 次），传输层现在会自动原地重开一次；如果用户侧仍然看到「偶尔第一下打不开、退出去再进来就好了」，就是这层自愈没兜住，把当时的控制台段发我 |
