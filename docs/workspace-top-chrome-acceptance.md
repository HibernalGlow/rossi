## A. 默认那一档（回归风险最高：升级之后顶栏整个没了）

- [ ] **W1 桌面冷启动**：不带任何快照启动（或先「重置布局」再重启）⇒ 窗口顶部**没有**工作台那一行，
      鼠标贴到最顶端也**不淡入**任何东西；内容从窗口顶端铺满。
      失败长这样：仍然能唤出一条顶栏。
- [ ] **W2 触摸屏冷启动**（Android / iPad）：同样没有顶栏，但**内容第一行不被状态栏压住**
      （这一截现在由 `SafeArea` 让出来）。
      失败长这样：第一条页签 / 书名钻到状态栏底下。
- [ ] **W3 老快照升级**：用旧版本存一份布局（拖过宽度、折叠过某条泳道、面板换过位置），
      换到这一版启动 ⇒ **顶栏没了，但其余布局一项没丢**。
      失败长这样：布局跟着回到出厂（说明缺键被当成整组非法）。

## B. 出口（顶栏上那颗返回键没了，靠这三条）

- [ ] **W4 桌面 `Esc`**：在工作台任意位置按 `Esc` ⇒ 回到进入前那一页。
- [ ] **W5 触摸屏系统返回**：Android 返回键 / iOS 侧滑 ⇒ 退出工作台。
- [ ] **W6 泳道菜单那颗「退出工作台」**：左栏 / 阅读器 / 右栏**三条**的「更多」菜单里都有这一项，
      按下去真的回到进入前那一页（不是只关掉当前漫画）。
      两条入口都要试：栏头那颗 ⋮ 按钮，以及**右键栏头整行**。
- [ ] **W7 沉浸四边栏 + 触摸屏**（**这一条是认下的代价，不是 bug**）：
      切到沉浸四边栏（设置 → 布局 → 默认启动视图）且顶栏关着 ⇒ 那边没有泳道栏头，
      界面上**没有**可见出口，只剩系统返回键。
      请确认这个观感可以接受；不接受就要另立一条出口（浮标 / 抽屉里加一颗），
      那属于新决策，不要按「修 bug」改。

## C. 开关往返与持久化

- [ ] **W8 往返**：菜单里点「显示工作台顶栏」⇒ 顶栏立刻回来（桌面 = 贴顶唤出的浮层，
      触摸屏 = 占一行的常驻栏）；再点「隐藏工作台顶栏」⇒ 没了。
      第二次的标签必须是「隐藏…」，说明账跟着状态走了。
- [ ] **W9 重启保住**：开着顶栏退出应用再进 ⇒ 还开着；关着再进 ⇒ 还关着。
- [ ] **W10 重置布局**：开着顶栏时按顶栏那颗「重置布局」⇒ 顶栏自己回到默认（关），
      且重启不会又变回开着（磁盘上那份要一并作废）。

## D. 边界（原有行为不许变）

- [ ] **W11 阅读器全屏铺满**：无论开关开着还是关着，进入全屏铺满后顶栏都不出现，
      退出全屏后回到该档本来的样子。
- [ ] **W12 上唤出区**：顶栏关着时，「设置 → 布局 → 悬停唤出区」里画的上边那块**不再唤出东西**
      （它只服务于顶栏）。阅读器自己的底栏唤出不受影响。
